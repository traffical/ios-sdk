Host-safety hardening (sdk-spec 0.10.0, S11): the SDK no longer terminates the host app on malformed backend data or hostile app input. Fixes, each reproduced in a release build against 0.7.0: NaN/Infinity reaching `JSONSerialization` (an uncatchable ObjC exception from `track` values/properties, getter defaults, logged context fields, or `"NaN"`/`"Infinity"` strings in bundle and resolve numbers) — every write now goes through a sanitizing writer and non-finite numbers serialize as JSON `null`; `Int(Double)` traps in the `int()` getter (out-of-range values now return the caller default and are reported), `suggestedRefreshMs`, and dynamic allocation counts; integer overflow in bucket folding (a huge `bucketCount` that persisted into a crash loop), bucket-range width, and the refresh sleep; division by zero from an unvalidated `localConfig` or cache; unbounded recursion from a re-entrant `assignmentLogger`; and data races on refresh state. Bundles are now validated at every ingestion point (network, `localConfig`, disk cache) with the JS SDK's rules plus `bucketCount ≤ 2^31−1` and safe-integer range bounds; a failing cache file is deleted. Behavior changes: bundle sources follow spec S8 (disk cache before `localConfig`), and the stored ETag is no longer sent when serving `localConfig`; unknown policy states are inactive; wire numbers must be finite and integers exact (no truncation or saturation); `suggestedRefreshMs` is clamped to [1 s, 24 h] and a `0`/negative hint is ignored (previously a hot loop); dynamic allocation counts must be number-typed and within [1, 10,000]; `initialize()` starts background refresh even when the first fetch fails, and never twice. Event delivery is bounded: single-flight flushes, a persisted backlog capped at `maxQueueSize` (oldest dropped) and delivered in chunks of at most 100, and non-retriable 4xx responses dropped instead of resent forever. New API, matching the JS SDK: `onError` option (every contained error, deduplicated), `getDiagnostics()` (`resolutionErrors`, `rejectedBundles`, `sideEffectErrors`, `droppedEvents`, `lastError`), and `TrafficalDecisionMetadata.reason` (`.resolved` / `.default` / `.noBundle` / `.error`). Adds the release-configuration `TrafficalHardeningTests` target (crash regressions, the sdk-spec `hostile_bundles.json` vector, and a deterministic mutation fuzzer over every spec bundle), SwiftLint `force_unwrapping` plus custom rules banning raw JSON writes and unchecked integer conversions, and advances the sdk-spec submodule to v0.10.0.
